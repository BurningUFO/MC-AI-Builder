# M5-A Windows 启动与游戏内聊天

## 三步体验

1. 在资源管理器打开项目文件夹，双击 **Start MC AI Builder.cmd**。首次可选择隔离练习世界或已管理的 BMC4 存档副本。后续双击沿用上次的选择。 [真实世界副本指南](m5-b-guide.md)看到 **已连接** 后即可使用。若提示 ChatGPT 登录，点击 **ChatGPT 登录**，在浏览器完成登录。
2. 在游戏聊天栏输入 `@Builder 你好，介绍一下你现在能做什么`。关闭聊天栏后按 **Alt+B**，再打开聊天栏，直接输入「请在原点 6 -60 6 朝北设计一面 8 格宽 3 格高的中世纪窗墙，用深色橡木和石砖，窗户用透明玻璃，保留台阶」。聊天会显示材料、版本和审阅结果。点启动器里的 **最新预览**，可打开两个角度的图片或 Blender 工程。确认方案后，在游戏聊天中点 **批准**。
3. 看到 NPC 正在砌墙时，直接说「先暂停施工，把窗户换成蓝色玻璃，其他部分保持不变」。审阅变更并再次点 **批准**。按 **Alt+B** 退出对话模式。体验结束时点启动器里的 **保存并退出游戏**。

## 首次配置

启动器识别当前项目的 `.venv`、Java 17 JDK、Forge 1.20.1（47.4.20）版本目录与 Blender。路径缺失时点 **设置**，选择 JDK 文件夹、包含版本 JSON 和 JAR 的 Forge 版本文件夹，以及 `blender.exe`。保存后点 **启动 / 重连**。路径保存在项目的本地缓存中。

- 从空仓库安装时，请先在项目目录准备 Python 3.13 虚拟环境、安装 `requirements-codex.txt`，并按首次构建说明用 `tools/m1.ps1 Build` 获取 Forge 和 Fake Players 依赖。日常启动只在源码内容或 Bridge JAR 变化时重建。 [首次构建与 Blender 安装](README.md)
- 若检测到通过本地验收的 BMC4 隔离环境，启动器复用其 387 个模组和默认配置，在 `mc-test` 下打开专用练习世界。找不到该来源时打开最小 Forge 练习世界。默认练习世界使用预置材料。可在 **设置** 选择下次使用独立的生存供料世界，再按 M4 流程授权箱子。 [生存供料操作](m4-guide.md)
- BMC4 首次加载可能要几分钟。若出现 Guardian 提示，可保留备份选项并选择 **Proceed**。图形界面会在进入世界后继续等待 Bridge 和 Agent 心跳。

## 聊天、审批与停止

- `@Builder` 不区分大小写，位于消息开头。对话模式开启时，聊天输入框上方会显示 **MC Builder 私聊**。`@Builder` 和对话模式需要安装带有这些入口的 Forge Bridge 客户端，并连接已启用 Architect 的世界。
- 打开 **选项 → 控制 → 按键绑定 → MC AI Builder** 可改快捷键。普通文字按对话模式设置路由，斜杠命令始终保留原有行为。切换模式前先关闭聊天栏。切换世界会重置模式。Agent 未连接时，定向消息会显示错误并结束。
- 发给 Builder 的指令仅走 Architect 游戏命令。Forge 继续检查玩家身份，且只接受聊天里的原有审批按钮或对应的显式审批命令。
- **停止 Agent** 可单独关闭 Runtime。Minecraft 保持运行，已经批准的施工仍受原有 Forge 控制。需要恢复对话时点 **启动 / 重连**。**保存并退出游戏** 会让 Minecraft 按正常流程保存并停止 Runtime。
- **Agent / 启动日志** 和 **Minecraft 日志** 可打开本地排错记录。遇到端口占用时，关闭占用程序后点 **启动 / 重连**。若出现登录失败且浏览器已经登录，打开登录检查日志核对原因。
- Codex 使用独立的 `%LOCALAPPDATA%\MC-AI-Builder\codex-home`。首次使用时，通过启动器的 **ChatGPT 登录** 在官方网页完成一次登录。模型为 `gpt-6.2-sol`，推理强度为 `medium`。
- 启动器显示当前任务的 100 回合、3,000,000 Token 本地预算。**启动 / 重连** 会继续使用当前 SQLite 账本。开始下一项工程前点 **新任务预算**，原账本继续保留。每回合先预留 24,000 Token，按 SDK 回报的实际用量结算。游戏会分别提示本地预算耗尽和 ChatGPT 服务端限制。
