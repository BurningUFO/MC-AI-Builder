# M4 生存施工与模组兼容规划

M4 在 M3 交互和 M2 持久化施工之上，引入受限的生存物资管理和逐类验证的模组方块支持。

1. 读取 NPC、工作区箱柜和可交互库存，形成与施工版本对应的材料清单。将玩家明确批准的供料源和施工范围记录在案。
2. 建造前报告缺料、工具与损耗需求。通过可验证的游戏交互取放物品，逐格扣料，记录剩料和拆除掉落。缺料或工具失效时暂停。
3. 从 BMC4 隔离实例选一组普通模组方块，再验证少量方向、支撑或多格状态。每类建立放置、完整状态回读、拆除和恢复测试。
4. 复用 M2 的施工记录验证中断前后的库存、掉落、世界与动作。覆盖玩家改动箱柜、缺料、工具损坏和跨版本材料重算。
5. 在独立世界演示自然语言提案、真实审批、缺料补给、拆换和完工。记录 Forge 事件、实际库存差额、世界终态与正式存档隔离条件。

交付可复现的物资用例、BMC4 白名单方块兼容报告、运行说明和 M4 验收证据。
