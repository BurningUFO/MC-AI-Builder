# 设计和建造单层木石住宅

1. 双击 `Start MC AI Builder.cmd`，启动已隔离的 BMC4 副本和 Codex Agent。在启动器开启 NPC 图像共享。沿用 [真实世界副本指南](m5-b-guide.md) 在游戏内批准施工区、NPC 出发点、建议原点和原版供料箱。建议原点是住宅地板的中心。为入口和 NPC 通行留出空间。
2. 输入 `/architect survey 请观察场地，设计一栋 7 格宽、9 格深的云杉石砖小屋，带透明玻璃窗、平屋顶、长凳和桌台。根据现场选择入口和窗组。` 聊天会给出选址理由、用料和预览路径。打开预览目录的 `revision-review.blend`，在场景列表选择 `Interior cutaway` 查看室内，或直接打开 `proposed-interior.png`。正面和侧后方图像在同一目录。
3. 把材料放进获准的供料箱，回游戏批准已审阅的候选。想中途换窗时，可以用 `@Builder 先暂停施工，把透明窗换成蓝色玻璃，入口和屋顶保持原样`。查看新的差异和预览，再批准新版本。重开后回到施工区附近，让原来的 NPC、仓库和施工区加载，然后确认继续或批准待审的改图。

## 可调整的组件

- 占地宽度和深度各选 7 或 9 格。地板下可加一格高的石砌支脚，跨过最多占地一半的一格低洼。场地需有实心支撑、无积水且保留施工通道。地形、已有方块或越界冲突会显示在审阅中。
- 木石墙体有紧凑、成对和宽窗组。门洞可偏左、居中或偏右，左右以站在屋内面朝正门向外看为准。室内净高两格。入口目前是可通行的门洞。室内可留空、放长凳，或放长凳和桌台。
- 屋顶可选平顶或单格前檐。用料限定在 Forge 验证过的原版方块和 BMC4 白名单内。供料箱库存由施工系统实际核对。
- 原点、朝向和已勘察占地随方案保留。想换位置或扩大地基时，先重新勘察。门扇、楼层、分隔房间和人字屋顶属于后续能力。

## 施工期间并行规划

在启动器设置中勾选「副本中的住宅施工启用并行 Codex 规划」，然后启动或重新连接 Agent。副本中符合条件的住宅到达施工阶段时，Agent 会使用现有 Codex 预算评估下一阶段。开启图像共享后，它可在 NPC 施工途中请求一次真实第一人称观测，必要时再请求一张。启动器同时显示 NPC 的动作、当前版本、进度和规划结果。

批准开工后，可以用 `/architect plan 建议先铺屋顶背侧，给入口留出通道` 提交顺序建议。策略只可调整已经批准且尚未开始的屋顶工作组。新增、拆除、更换材料或改变范围仍通过原有审阅和审批。模型超时或策略过期时，NPC 继续按确定性的安全顺序施工。捕捉不到配对画面时，规划器可以改用结构化数据。玩家可以正常暂停、取消或另行发起改图。

## 把批准的副本工作区交给 Builder

1. 标记副本施工区、NPC 出发点、原点和朝向，执行 `/architect site autonomy auto`。用 `/architect site protect x1 y1 z1 x2 y2 z2` 标记必须保留的方块，再通过 `/architect site review` 一次确认整个范围。供料箱沿用 `/architect supply`，需要的铲、镐、斧和剪刀由实际库存提供。
2. 输入 `@Builder 这块区域交给你，帮我建栋木石住宅。挡路的草木、泥土和普通木石你来处理。`。也可以用 `/architect work` 发起任务。Builder 比较现场和候选布局，解释选择，再按已签许可连续清障、取料和建造。箱子、机器、标记过的资产和影响工作区外的动作会单独反馈。若 Builder 提问，可用 `/architect work 保留箱子并绕开` 回答，原任务目标随同这次答复继续处理。只想看方案时，用 `/architect survey` 或在需求中明确「只设计」。
3. 用 `/architect worksite` 或启动器查看许可、清障进度和工具。缺料时补给原授权箱，再通过游戏内继续。用 `/architect site autonomy revoke` 撤销自主许可。需要重新授权时，重新审阅施工区。图像共享由启动器单独控制，关闭后自主勘察使用 Forge 的结构化现场摘要。预览恢复后，可用 `/architect work retry` 重新核对已保存的自主方案。
