# M6-B 视觉与局部世界状态

## 使用

授权玩家在隔离世界操作 `/architect observe`。Forge 将画面与当前 NPC 周围的局部方块样本绑定在同一观测 ID 下。配对要求服务端拍摄前后和客户端渲染帧的方块状态指纹一致，并校验 Tick、姿态及施工版本。

使用实例的 `config/mcaibuilder-architect.json` 在项目根目录运行以下只读检查。默认在本地列出图像摘要和相对场地数据。

~~~powershell
.\.venv\Scripts\python.exe -B -m src.architect.vision --config '.\mc-test\<实例目录名>\config\mcaibuilder-architect.json'
~~~

查看该观测的本地 PNG 后，可以在同一命令末尾显式指定 `--share-image <观测ID>`。仅当选中的观测 ID 仍为当前有效配对时才会调用 Codex。结构化报告保存为实例观测目录中的 `analysis-latest.json`。该入口使用现有 ChatGPT 登录、`gpt-6.2-sol`、`medium` 和启动器的持久化预算。

## 采样与数据边界

- 默认窗口为 9 × 9 × 7 个方块，读取批准区域及一格监测边内的已加载部分。输出站立高度网格、相邻可站立点的连通性、最多 36 个精确方块 ID 和 BlockState，以及已知碰撞、液体和危险提示。窗口外、授权边界外和未加载区域不作推断。
- 观测保留最多 60 秒。阶段、NPC 姿态或方块状态变化后，重新请求合格配对。连通性是本地脚下和头顶的保守检查，实际移动仍需真实寻路。
- 视觉报告验证结构和坐标。超出精确样本的方块断言标为未知，明确状态不匹配时标为冲突。报告只供审阅。
- 转交 SDK 的内容是限量相对地形、方块、视角及施工状态字段，以及一张已校验的 RGB PNG。使用低信任 `ExternalMessage` 的工具输出语义，并剔除 PNG 附加元数据。现有只读沙箱、禁用工具和禁止自动批准的配置同时保留。

## 验收状态

Forge 离线构建和 38 项 Python 测试通过。最小 Forge 与 387 模组 BMC4 的隔离实例均用真实游戏运行本地模拟后端。部署 JAR 与构建产物一致，两个实例正常退出。证据同时记录了采帧耗时、像素读取耗时和采集帧率。

两套环境中，服务端拍摄前后采样跨度均为 6–8 Tick，渲染帧与配对回读相差 3–4 Tick。测试玩家通过原版交互增加一级台阶后，旧配对返回 409，重新通过有效采样测得连通站位高差为 1。客户端真实卸载邻近区块后，有 108 格标为未加载，受影响画面无法取得可提交模型的配对。未授权令牌、过期或错配观测、损坏 PNG 以及带施工动作的模型输出均有拒绝用例。

### 真实 Codex 对照

按授权发送了纯测试场景的三张 731 × 432 NPC 视角 PNG。前两轮使用逐字节相同的 3,130 字节 Forge 摘要，摘要保留两种真实材料和相对地形，省去朝向字段。两张图片的哈希不同。第三轮使用真正拍到的一级台阶和蓝玻璃，并在送审样本里把中心方块故意写成橡木。原 Forge 样本保留原样，供结果复核。

| 观测 | 模型认出的中心表面 | 地形 | 结论 | 耗时 | Tokens |
| --- | --- | --- | --- | --- | --- |
| 蓝玻璃 | 蓝色玻璃 | 平坦 | 一致 | 21.787 秒 | 13,269 |
| 橡木 | 棕色木板 | 平坦 | 一致 | 19.606 秒 | 13,307 |
| 台阶与冲突参考 | 蓝色玻璃 | 一级台阶 | 冲突，列出不确定性 | 20.017 秒 | 13,416 |

第三轮中心偏移 `[0, 1, -3]` 的橡木断言与原生 Forge 蓝玻璃状态不匹配，模型提出的另外四个位置全部通过核验。三轮共计 **39,992 Tokens**，已记入隔离验收的持久化账本。有效配置记录确认 `gpt-6.2-sol`、`medium`、只读、无联网搜索和无 MCP。三轮后测试游戏正常保存退出。
