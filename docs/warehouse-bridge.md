# 教堂仓库的三孔石拱桥

桥沿门洞中线过水，用灰蓝页岩砖做桥体，白石英描出拱圈和桥面边线。方解石砖墙和低矮的石英柱呼应教堂的浅色石柱。青蓝灵魂灯笼分布在桥头和中墩两侧。

## 尺寸和落位

| 项目 | 样例尺寸 |
|---|---|
| 桥身总宽 | 9 格 |
| 连续可走主道 | 7 格 |
| 两侧栏杆 | 各 1 格 |
| 总长 | 25 格，含两端各 2 格桥台 |
| 三个拱的放样列宽 | 5 格、7 格、5 格 |
| 水面到桥面踏面的高度 | 4 格 |
| 中拱中心的水面以上净高 | 3 格 |

在门洞的 7 格中找正中的一格，对准桥面唯一的石英砖中线。桥面顶面衔接现有教堂台阶的一整排踏面，岸边的高差可以用同宽的 7 格短阶接齐。

先量教堂的衔接踏面到岸边衔接线的实际长度。25 格是示例。距离略长时，可沿轴线延长靠岸的平直桥台，保留三个拱的比例。实际河床和水位决定支墩向下补砌的深度。

## 放样

把横向编号为 X，长度方向编号为 Z。X=0 和 X=8 是栏杆，两端的主道均为 X=1–7。示例以水面为 Y=0，桥面方块在 Y=3，所以踏面顶是 Y=4。

桥面横向排列如下。

~~~text
X    0      1      2      3      4      5      6      7      8
   护栏    灰蓝    浅灰    浅灰    石英    浅灰    浅灰    灰蓝    护栏
~~~

| Z 列号 | 部位 |
|---|---|
| 0–1 | 岸侧桥台 |
| 2–6 | 小拱 |
| 7–8 | 实心桥墩 |
| 9–15 | 中拱 |
| 16–17 | 实心桥墩 |
| 18–22 | 小拱 |
| 23–24 | 教堂侧桥台 |

1. 桥台和桥墩在相应的 Z 列砌满 9 格宽。样例从 Y=-3 砌到 Y=2。
2. 每孔按下表找拱底。每一列的弧形件横铺整桥宽度，两侧用白石英，内侧用页岩砖。倒置楼梯的下半块朝最近的桥墩或桥台。弧形件上方至 Y=2 的空位用页岩砖砌实。
3. 在 Y=3 铺通桥面。X=1、7 用磨制页岩压边，X=4 用石英砖做中线，主体铺磨制闪长岩。X=0、8 用平滑石英收边，在 Z=4、12、20 换成雕纹石英块收出拱心。Z=0、7、17、24 的中线两旁再各铺一块石英砖，和灯柱位置呼应。
4. 在 X=0、8 铺栏杆。Z=0、7、12、17、24 用石英柱代替矮墙。Z=0、7、17、24 的柱顶各放一盏灵魂灯笼，Z=12 用一块平滑石英下半砖收顶。

| 拱孔 | 从左到右的拱底部件 |
|---|---|
| 小拱 | Y=0 倒置楼梯，Y=1 倒置楼梯，Y=2 上半砖，Y=1 倒置楼梯，Y=0 倒置楼梯 |
| 中拱 | Y=0 倒置楼梯，Y=1 倒置楼梯，Y=2 倒置楼梯，桥面底，Y=2 倒置楼梯，Y=1 倒置楼梯，Y=0 倒置楼梯 |

模型使用本机 BMC4 的 Quark 页岩砖系、磨制页岩和方解石砖墙，以及原版的平滑石英、磨制闪长岩、石英砖、石英柱和灵魂灯笼。Blender 的水面用来示意拱孔和倒影。

在仓库根目录用 PowerShell 重建样例。

~~~powershell
$instance = '<PCL 的 BMC4 版本目录>'
& .\.venv\Scripts\python.exe -B -m src build --instance $instance --sample warehouse_bridge
~~~
