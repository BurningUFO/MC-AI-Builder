# M3 游戏内指令与确认

M3 把游戏聊天里的建造请求接到 M2 的候选版本与批准流程。沿用 `Building`、Forge Bridge、版本哈希、世界回读及原有的 NPC 执行器。

1. 在独立测试世界接收游戏内指令。服务端取得发言玩家身份和当前施工点，检查谁可以提交、批准和拒绝。
2. 将自然语言转成可校验的建造意图。先使用确定性的测试解析器验证流程，再以提供方接口接入 LLM。输出包含建筑 ID、基础版本、请求修改的内容及需要澄清的字段。
3. 根据解析后的意图生成 `Building` 候选版本。沿用世界回读和差异审阅，在聊天中返回版本、变化数量、冲突位置以及可用的预览入口。
4. 将游戏内确认与发言者、候选 ID 和审阅哈希绑定。世界或基础版本变化时要求重新审阅。拒绝或超时后保持施工暂停，玩家可选择恢复原任务。
5. 验收覆盖有效请求、含糊请求、未授权批准、过期确认、重复确认、玩家冲突和重启后的待审阅候选。在独立世界演示一次聊天到增量施工的完整闭环。

交付游戏内命令、意图接口、可配置提供方、使用说明和真实游戏证据。保持 M2 的权限边界和真实物品交互，将生存采集、补货与完整库存策略留给 M4。
