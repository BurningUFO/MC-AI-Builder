# M6 游戏内体验

1. 双击 `Start MC AI Builder.cmd`，选择已隔离的 BMC4 副本。在设置里显式勾选允许 NPC 图像发送给 Codex，然后启动或重连 Agent。启动器沿用 ChatGPT 登录、`gpt-6.2-sol`、`medium` 和同一预算账本。
2. 在副本用 `/architect site` 标记并批准施工区、NPC 出发点和建议原点，再用 `/architect supply x y z` 指定供料箱。输入 `/architect supervise 请先看看这块地，设计一面六格宽的窗墙。施工到一半帮我复查窗洞是否清楚。` 用聊天里的预览位置或启动器的「最新预览」打开 Blender 审阅。
3. 点击游戏聊天里的候选批准按钮。施工半程暂停时查看复查结果，再点击继续或批准一份新的修改。完成后查看 NPC 的视觉报告和 Forge 逐方块核验。

`/architect survey <需求>` 只进行施工前主动观察与设计。`/architect supervise <需求>` 同时为批准的任务启用施工复查。`/architect inspect <需求>` 可按需暂停并复查当前被监管的任务。监管时通过 `@Builder` 或 Alt+B 说「先暂停，把窗户换成蓝色玻璃」也会触发观察和改图审阅。

`/architect observe` 保留本地只读相机入口。普通 `@Builder` 对话和 Alt+B 仍按原方式使用。图像共享设置仅作用于需要图像的副本任务，关闭选项后重启 Agent 生效。任何继续、修改和开工按钮仍在游戏内由玩家操作。

## 复查和恢复

- 复查由施工阶段触发。每次施工复查最多送审两帧，渲染延迟导致错配时可在同一姿态重取一次有效样本。到达半程时先暂停，失败和完工各发出有限的复查。Forge 优先从原站位看向已建目标。需要换位时，复用 M6-C 的安全站位检查和短距离原生寻路。
- 画面评估影响修改建议，Forge 审阅检查真实方块、状态和保护范围。修改候选绑定当前版本和审阅哈希。
- 相机失效、模型超时或观测过期时，聊天会反馈原因。可检查副本是否加载、回到施工区，然后重新检查或由玩家确认继续。
- 正常退出由启动器保存副本。重开后先让玩家、NPC 和供料箱所在区块加载，再检查原审批或重新审阅。适用范围为受管理的单人副本与现有窗墙、供料和已核验材料。
