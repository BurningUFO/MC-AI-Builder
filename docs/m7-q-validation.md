# M7-Q 自主施工验证

## 原有约束与改造

| 原有约束 | M7-Q 中的用途 |
| --- | --- |
| 勘察淘汰地基上所有非空气方块，首次计划拒绝已占目标 | 候选同时保留可施工的方案和受限方案。模型比较原点、布局、清理量、工具和风险，再选择施工、换位或请玩家决策 |
| M2 只拆除当前任务拥有的方块 | 保留 M2 的修改规则。首次自主施工另有签署的工作区权限和专门的清障步骤 |
| 区域、玩家、现场指纹、仓库、原生交互和恢复核验 | 继续核验。自主请求需要未到期的同一副本、同一玩家和同一份范围授权 |
| M7-P 同层邻近施工、分批仓储和后台规划 | 完成清障后，按原有施工和异步规划路径执行住宅 |

玩家可以一次签署工作区自主建设许可。Forge 把原生方块属性、障碍组的相对位置和候选方案的清理量交给模型。模型选择布局、朝向和先做什么，选中方案直接进入连续的清障、取料和建造。普通木石以实际可挖掘性和支撑关系安排动作，天然与玩家放置的普通木石共用工具和挖掘路径。功能方块、标记资产、危险流体和范围外影响集中反馈。

Fake Player 在工作区内使用正常挖掘速度和真实世界事件。徒手处理草与普通灌木，用剪刀处理树叶，铁铲处理表土，铁镐处理天然石头，铁斧处理树干。草叶和木石的实际掉落记在世界中。NPC 库存不计入世界散落材料。存档重开读取仍存在的对应掉落实体，缺失或合并的实体以待核对记录呈现。

建筑上限沿用 512 方块，现场准备最多 512 处。相连的待清理方块按支撑排序，双格植被一次挖掘并核对上下半部。执行中出现的普通可挖掘障碍可以在待放置位置插入清障，沿用同一建筑版本和检查点。之后由玩家更改的位置保持冲突保护。

## BMC4 实机记录

### A 普通植被与自动开工

保留了原地的 16 株草和 2 株回移植灌木。模型比较了原点的 18 处清理与一处偏移候选的 11 处清理，按玩家要求保留原点、正北朝向和偏左入口，选择优先清理通行位置。Forge 在原点核验到零冲突。

初次预览发现回移植资源位于模组 JAR 的 `minecraft` 命名空间。修复资源查找后，原方案生成了 Blender 文件和三张预览。缺少静态模型的现场障碍在当前场地视图保留标注轮廓，建筑模型继续用经过校验的完整方块资源渲染。同一工作区签名下，`/architect work retry` 复核了现场与已批准供料箱，沿用同一个模型结果。测试玩家通过箱子补入模型选中的屋顶板材。

Fake Player 完成 18 次真实徒手挖掘和 183 次真实放置。相同的 183 位置复用了 M7-P 住宅几何，63 处屋顶材质由云杉木板改为模型选择的石砖台阶。回读与已生效方案 183/183 匹配，额外检查 5,613 处位置，其中 1,806 处位于批准范围外，均无非预期变化。游戏按原生流程正常保存退出。

### B–D 混合地形、普通木石与重要资产

在同一合成副本保留真实生成的草木，并由测试玩家摆放挡住占地的两层木石结构。固定原点的请求碰到装有物品的箱子、展示基座和标记石砖。模型合并说明并等待决策，未产生施工动作。允许调整布局的请求选择了相对原点向东 2 格、向南 3 格，完整保留大树和西侧设施，把挡板与临近土石纳入实际清障队列。

选中的 7×9 住宅方案包含 183 格目标和 26 处准备，涉及 21 处植被、2 处表土、1 块天然石头和 2 块玩家放置的木石。现场复核零冲突。Fake Player 按同一许可开工，移除 22 处后在需要铁铲时暂停，游戏正常保存。重开和补给后完成其余清障和 183 次放置，两块挡板均由原生交互拆除，铁铲、铁镐和铁斧每次相应挖掘扣 1 点耐久。最终回读 183/183 通过，额外核对 7,061 处位置，其中 2,058 处在批准范围外，均无非预期变化。原供料箱的转运有收支记录，受保护箱子的库存完全一致。

### E 恢复和边界

缺铁铲时正常保存退出。重开核对了同一个 Fake Player、施工队列、库存、供料箱和 5 件尚在地面的掉落物。进入下界后实测施工区卸载，异维度续工请求被拒。返回并重新加载后，测试玩家用原生箱子菜单补入铁铲，原任务继续。另一副本凭据、越界方案、过期请求和模拟模型超时均未改变现场。另用真实游戏命令验证了撤销、旧工作区任务重放和一次实际到期。满背包分支使用真实服务器中的模拟库存，取料预检和转运规划均拒绝，箱子与模拟库存一致。

两个合成副本均使用原生保存流程退出，四个正式存档和源模组目录的文件哈希保持一致。

### F 异步规划和施工效率

首次开工至暂停为 19.003 秒。重开后的有效施工时间为 103.633 秒，其中剩余清障用了 2.605 秒。两段共记录 7 批真实转运。施工阶段的模型按位置和可用站位选了先铺屋顶背侧，Forge 应用该顺序。模型思考期间 NPC 完成 43 次原生放置。该方案与 M7-P 对比使用一致的 183 格建筑状态，恢复、清障和施工均由同一个 NPC 执行。
