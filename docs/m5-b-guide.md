# M5-B 真实 BMC4 世界副本

## 开始体验

1. 在 Windows 双击 **Start MC AI Builder.cmd**，点 **选择世界**。在「复制 BMC4 存档」中选一个已正常保存退出的单人世界。复制、校验结束后点 **启动 / 重连**。以后启动器会沿用上次选中的世界。列表中的「隔离练习世界」仍可使用。
2. 进副本后按下表标记施工区、NPC 和建筑原点。点游戏内的 **批准施工区**，再走到范围内的原版单箱旁，面对箱子输入 `/architect supply`。放入所需材料后，可用 `@Builder` 或 Alt+B 提交建筑需求。
3. 打开启动器的 **最新预览**，在游戏聊天里批准对应方案。施工中可以要求暂停并改图，重新审阅后再批准。结束时用 **保存并退出游戏**。若 BCLib Guardian 要求确认，保留备份并选择 **Proceed**。

## 游戏内授权

| 操作 | 命令 |
| --- | --- |
| 查看施工区、维度、仓库及区块状态 | `/architect site status` |
| 标记长方体的两个对角 | `/architect site pos1`、`/architect site pos2` |
| 标记 NPC 出生点 | `/architect site spawn` |
| 标记建筑原点和朝向 | `/architect site origin`，可在末尾指定 `north`、`east`、`south` 或 `west` |
| 审阅并确认施工区 | `/architect site review`，再点聊天中的 **批准施工区** |
| 清除未提交标记 | `/architect site reset` |
| 撤销当前区域及供料授权 | `/architect site revoke` |
| 批准看向的单箱或指定坐标 | `/architect supply` 或 `/architect supply x y z` |
| 结束施工后单独撤销供料箱 | `/architect supply revoke` |

`pos1`、`pos2`、`spawn`、`origin` 默认使用脚下位置，也接受显式 `x y z`。位置须在当前维度且距玩家不超过 32 格。区域要覆盖完整建筑、NPC 脚下与头部、供料箱及步行路线，含一圈边缘最多 24,000 格。建筑师向模型提供的是相对坐标。副本中更换原点和朝向时，需由玩家重新审阅施工区。

## 副本范围和限制

- 原存档及启用模组仅作读取来源。启动器复制完整世界树，包括各维度、实体、玩家和 `serverconfig`，逐文件核验。会话锁由副本单独建立。游戏进程使用项目 `mc-test/world-copies` 中的专用实例和世界标记。副本客户端关闭了失焦自动暂停，以便外部审阅时继续运行。
- 副本单人客户端复用存档记录中的本地玩家 UUID 和名称，用来加载玩家状态与校验授权。该身份适用于本机单人副本。微软联机认证留待正式联机适配。副本初次进入保留原有游戏模式、位置和维度。
- NPC 在已加载、批准范围内使用原有寻路及物品交互。可在自然地面和高低差中施工和搬运。需要从上方放置半砖时，NPC 能在有净空的安全站位原地跳跃，并从实际视线和交互距离重新核验。草木、已有方块、缺少支撑及边缘敏感方块会出现在审阅报告中。实心方块覆盖草地时，审阅会列出范围内可能自然变成泥土的草方块。找不到可达站位或通道时，NPC 会暂停并在聊天栏报告原因。可先处理现场或重新选址，再审阅。
- 区块卸载时施工暂停并保留检查点。回到范围附近后，核对现场、库存及当前计划再确认继续。撤销或更换区域会停止旧任务，保留记录与已在世界中的 NPC 和物品。
- 客户端使用 BMC4 副本的客户端和模组配置，施工材料仍由现有白名单校验。默认仍是 `gpt-6.2-sol`、`medium`，沿用启动器的 Codex 登录与预算账本。 [基础聊天及启动说明](m5-a-guide.md)
