# 月隙观星台

南侧入口接弧形档案厅。星盘地坪引向三折楼梯，途经测绘夹层，抵达装有浑仪的塔顶。悬桥有两格可走宽度，通往开放侧台。下沉观测盘从东西双向进入，以铜和石英刻线与望标标出观测方向。

体量草案比较了侧台设环和塔顶设环。选择塔顶承载双环浑仪，让入口、主塔与低侧台分担不同的构图作用。档案厅屋面以磨制页岩和两道氧化铜肋呼应塔身。侧台的低刻度与游览环线来自对 Jai Prakash Yantra 照片的观察，部件位置与构造依 Minecraft 尺度重新设计。

首轮铜环颜色偏亮，斜环近景可见断口。修订采用斑驳铜和半格曲面，在高差处增加搭接。蓝图走查还查出三折楼梯落脚处被护栏挡住，塔顶环下净空和铜环承座占用了过桥路线。修改后，从入口经两处楼梯平台、主塔顶和悬桥可以走到盘底，并验证了桥的另一条通道。
