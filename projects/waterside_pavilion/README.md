# 澄漪阁

澄漪阁是一座临水茶阁。安山岩中轴从南侧岸梯穿过五开间茶厅，通向北侧观景台。西北角的折形泊位可停船，靠水一侧设栏杆和坐凳。东侧双宽楼梯通往二层，四面开敞的柱间可观水，桌椅和盆竹围着栏杆布置。台基石桩由蓝图给出，选址时对准实际湖岸和岸梯标高。

两重檐都由逐列计算的半格高度生成，朝四角渐抬，适合用 Quark 青陶瓦的楼梯和台阶砌筑。上檐的两端收成山花，下檐环绕观景层。红树木柱与逐层挑出的托木形成檐下节奏，深板岩脊檐收边，暗海晶石点在梁头和脊尾。茶厅利用红树木活板门和竹活板门组合格扇，桌椅使用 BMC4 的 Twigs 与 Handcrafted 家具。灯笼预览显示纹理的第一个动画帧。

首稿快览的台基下方出现亮色矩形，室内座椅和檐下结构也偏暗。二稿把展示基面移至桩底以下，将审阅补光移进两层开间。实际方块改动包括加高上层一格、增设横梁、调整瓦脊和在茶厅加入竹格扇。复看外观和室内确认了桩基、檐间层次和格扇变化，剖面检查了楼梯与二层落脚处。
