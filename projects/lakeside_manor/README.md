# 苔岬庄园

庄园以通高炉厅为核心，西侧接低矮的四坡厨房翼，东侧卧室翼转向湖面。三段青灰瓦屋面共用一套骨架和屋檐做法，凸出的山墙、苔质石基、木阳台和向下伸出的码头形成临水轮廓。

- 首层北侧连陆上小径和厨房药草畦。南门经石露台接码头，入门后可直接到餐桌、壁炉起居区、厨房和储物工坊。
- 双宽楼梯通向环绕炉厅的回廊。东翼有白色精致床的客房和带红色双人精致床的主卧，主卧双门通到看湖阳台。
- Quark 青色陶瓦砖瓦形成屋面。Twigs 凝灰岩和苔圆石砖在岸边交替，深橡木框架搭配浅色墙板。Handcrafted 精致床、长椅与 Twigs 云杉桌取自本机 BMC4。

首稿的粗横梁压低了窗格，炉厅视角被木柱挡住。第二轮提高了下层窗格，新增采光老虎窗和外开窗板，对齐炉厅主轴并补光，卧室双门也打开到阳台。随后修正老虎窗玻璃的覆盖顺序，以完整静态模型的精致床替换天根木床的底模。

以 `building.json` 的 `y=0` 作为庄园地板基准。湖侧朝南，放置时给 `z=16–23` 的码头预留水面。蓝灰预览平面是 Blender 布景，码头和支承使用蓝图中的方块。
