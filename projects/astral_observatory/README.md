# 月隙观星台 · Moonrift Observatory

从偏心的弧形档案厅进入，经过书架、绘图桌和星盘地坪，上三折楼梯至测绘夹层及塔顶。悬桥把塔顶和单独承台上的露天观测庭联在一起。石英拱横贯庭中，切制铜和海晶灯标出刻度。庭内罗盘、观测基座和座凳围绕拱口布置。

青灰页岩与深板岩承担底座和支墩的视觉重量。黯缚石、紫色镶框玻璃和少量紫水晶瓦延续档案厅的夜色，暖铜把视线引向高处。档案家具用 Quark 书架与 Handcrafted 桌椅。[材料清单](materials.csv) · [成品外观](../../docs/previews/astral_observatory/approach.png)

首稿实渲里的楼梯塔顶两根短柱显得孤立。第二轮把它们改成带铜脊的折面檐棚，让登塔出口有遮蔽，又增设了悬桥铁栏和观测庭的方解石栏墙。同轮快览显示檐棚承接了档案厅的紫色屋面，观测近景同时呈现完整拱口、罗盘铺地和悬桥。源蓝图共 3,759 格，三折楼梯与过桥动线已检查净空。[首稿外观](versions/v1-first-study/approach.png) · [首稿观测近景](versions/v1-first-study/meridian.png)
