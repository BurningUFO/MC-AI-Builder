# 澄漪阁

南岸台阶和磨制安山岩中轴仍通向五开间茶厅，再到北侧观水露台与西北泊位。东侧双宽楼梯通到二层。上层柱列内退，外侧留出观水廊，桌椅和盆竹布置在通道两边。

体量草案比较了 27 格和 23 格宽的上屋面主体。选 23 格方案，令二层相对下檐有更清楚的收分。文昌阁照片里的薄檐与青绿梁头用于确定收边位置。BMC4 材料拼图里，Quark 青瓦实际偏灰蓝，暗海晶石的绿色更深，适合只留在檐角、脊线和短托木上。

首轮细化的通长绿边抢眼，屋脊下有整条外露木带，新柱还挡住二层的原机位。修订后把绿边收回檐角、压低屋脊，柱位避开中廊和相机。檩木遇到已铺瓦的位置让位，山花木面退到前坡的瓦后。茶厅图指出观廊边梁下方的一条透光缝，改用整格边梁后复看闭合。楼梯两条踏步线各通过走查，另验证了岸梯到茶厅、观水台和泊位的连续路线。
